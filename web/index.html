Instant Package Distribution Cross-Platform

Node.js (npm / npx)
npm install -g tplink-router-suite
# Run directly on-demand:
npx tplink-router-suite tplink-cli status
Python (pip / pipx)
pip install tplink-router-suite
# Run in isolated environment:
pipx run tplink-router-suite tplink-cli
Homebrew & POSIX
brew install dulithdivisekara/tap/tplink-cli
# One-line curl installer:
curl -fsSL https://tp-link-cli.dulith.me/install.sh | bash
