1-Minute AI Copilot Integration

Configure your favorite AI agent with the standard MCP stdio configuration.

// Edit ~/Library/Application Support/Claude/claude_desktop_config.json (macOS) or %APPDATA%\Claude\claude_desktop_config.json (Windows)

{
  "mcpServers": {
    "tplink-mcp": {
      "command": "npx",
      "args": ["-y", "tplink-mcp"],
      "env": {
        "TPLINK_ROUTER_IP": "http://192.168.1.1",
        "TPLINK_PASSWORD": "your_admin_password"
      }
    }
  }
}

// In Antigravity MCP settings or .cursor/mcp.json

{
  "mcpServers": {
    "tplink-mcp": {
      "command": "python3",
      "args": ["-m", "tplink_mcp.server"],
      "env": {
        "TPLINK_ROUTER_IP": "http://192.168.1.1",
        "TPLINK_PASSWORD": "your_admin_password"
      }
    }
  }
}

Enterprise Agentic Architecture

Designed to resolve the single-admin lock and prevent autonomous AI agents from ever disconnecting themselves.

1

Atomic Session Leasing

TP-Link gateways enforce a single active admin lock. The SafeSession context manager authenticates, executes the tool, and calls logout() immediately so your browser UI is never kicked.

2

Network Guard Protection

Automatically inspects default gateways and Wi-Fi SSIDs. Prevents AI agents from sending router commands if your laptop is currently connected to university Wi-Fi or a mobile hotspot.

3

Disconnection Safeguards

Disruptive actions like router_reboot, router_set_cell_lock, or band switching strictly require confirm=True to prevent an autonomous agent from severing its own remote session.

18 Typed MCP Tools

Strictly typed schemas following official MCP guidelines.

Tool Name Type Safety Guard Functionality
router_get_status Read Safe Full device telemetry, cellular link state, hardware and firmware versions.
router_get_rf_signal Read Safe Live 3GPP RSRP, RSRQ, SNR, signal bars, EARFCN, and PCI metrics.
router_set_cell_lock Write confirm=True Locks modem to specific tower EARFCN and PCI to prevent cell hopping.
router_set_lte_band Write confirm=True Locks modem to specific LTE band (e.g. Band 3 1800MHz or Band 8 900MHz).
router_get_connected_clients Read Safe Queries active DHCP table: hostnames, IP addresses, MAC addresses, and lease time.
router_manage_dhcp_reservation Write confirm=True Adds, deletes, or lists static DHCP IP address reservations by MAC.
router_get_data_limit Read Safe Returns monthly cellular quota, warning alert threshold, and billing reset date.
router_set_data_limit Write confirm=True Configures monthly cellular data quota in MB and billing cycle reset day (1-31).
router_get_wifi_networks Read Safe Returns status, SSIDs, channels, and operational state of 2.4 GHz and 5 GHz radios.
router_set_wifi_radio Write confirm=True Enables or disables Wi-Fi radio (2.4GHz / 5GHz) or renames active SSID.
router_get_led_status Read Safe Queries physical front-panel LEDs and Night Mode schedule state.
router_set_led_night_mode Write Safe Configures night mode to turn off router LEDs automatically during sleeping hours.
router_run_diagnostic Exec Safe Runs router-side WAN, physical cellular link, and NCSI internet reachability test.
router_set_dns Write Safe Configures custom WAN DNS resolvers (e.g. 8.8.8.8, 8.8.4.4).
router_toggle_ipv6 Write Safe Enables or disables IPv6 stack to mitigate dual-stack resolution delays.
router_run_ussd Exec Safe Sends interactive USSD balance code (e.g. *344#, *123#) and parses response.
router_read_sms Read Safe Reads incoming or sent SMS messages from router SIM inbox.
router_reboot Exec confirm=True Initiates graceful hardware reboot of the router.
Author & Architect • SLIIT Malabe

Engineered by Dulith Divisekara

Conceived and built in Malabe, Sri Lanka (near the SLIIT Campus area) out of necessity to stabilize an active Hutch 4G LTE unlimited 20 Mbps SIM running in a TP-Link Archer MR200 v5 router.

To overcome tower congestion and high bufferbloat, this server exposes live 3GPP RF telemetry, enables manual cell and band locking, and enforces an automatic Network Guard to prevent AI agents from ever executing commands when connected to campus Wi-Fi or mobile hotspots.
